# woad.Go - Example - **colour**


## Summary

Prints sample words using **woad** SGR foreground constants and **RESET**, mirroring the **woad** C example **examples/colour.c**.


## Source

See [examples/colour/main.go](./colour/main.go).


## Execution

```bash
go run ./examples/colour
```

On a colour-capable terminal the words appear in the named colours, then the SGR state is reset.
