# woad.Go - Example - **print_status**


## Summary

Prints sample status words using **woad** SGR foreground constants and **RESET**, mirroring **woad.Ruby** **examples/print_status.rb**.


## Source

See [examples/print_status/main.go](./examples/print_status/main.go).


## Execution

```bash
go run ./examples/print_status
```

On a colour-capable terminal the words appear in green, yellow, and red, then the SGR state is reset.
